    📱 ប្រើលើទូរស័ព្ទ Android តែម្នាក់ឯង (គ្មាន PC):
    1. ដំឡើង Termux ពី F-Droid
    2. ក្នុង Termux វាយ:
    pkg update -y && pkg install -y python ffmpeg
    pip install -U yt-dlp
    termux-setup-storage (ចុច Allow)
    3. ដាក់ index.html + server.py ក្នុង Folder Download រួចវាយ:
    cd ~/storage/downloads && python server.py
    4. បើក Chrome ហើយចូល http://127.0.0.1:8800
    វិដេអូនឹងរក្សាទុកក្នុង Download/VideoGrab

    💻 ប្រើជាមួយ PC (WiFi តែមួយ):
    1. នៅលើ PC: pip install yt-dlp
    2. Run: python server.py
    3. ទូរស័ព្ទ និង PC ត្រូវនៅ WiFi តែមួយ
    4. បើក Link ដែល server.py បង្ហាញ (ឧ. http://192.168.1.10:8800) នៅលើ Browser ទូរស័ព្ទ — App នឹងភ្ជាប់ដោយស្វ័យប្រវត្តិ
    5. ចុច Share → Add to Home Screen ដើម្បីប្រើដូច App ពិត

    ចំណាំ: បើបើក App នេះពី https (ឧ. GitHub Pages) ត្រូវប្រើ Server ដែលជា https ដែរ។ Link ផ្ទាល់ .mp4 អាចទាញបានដោយមិនចាំបាច់មាន Server។
